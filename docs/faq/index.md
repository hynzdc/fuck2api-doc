# 常见问题

## 接入类

### 为什么返回 401？

- Key 复制不完整
- Header 缺少 `Bearer `
- 使用了已吊销的 Key
- 环境变量未生效（新开终端）

### 为什么 404 Not Found？

- Base URL 少了或多了 `/v1`
- 路径写成了 `/chat` 而不是 `/v1/chat/completions`
- 域名指错环境（测试 / 生产）

### 本地 cURL 成功，客户端失败？

- 客户端读的不是你以为的那份配置
- GUI 缓存了旧 Key
- 客户端把模型名写死成了官方默认且你未开通

## 模型类

### 模型列表是空的？

- Key 权限过窄
- 管理员未配置渠道
- 请求打到了错误环境

### 同样模型名，效果和官方不一样？

可能命中了不同上游实现或映射。查看日志中的 `channel` 字段。

## 计费类

### 失败请求会扣费吗？

- 鉴权失败 / 参数错误：通常不扣
- 上游已开始生成后客户端断开：可能已产生 Token 费用

### 如何对账？

导出账单 CSV，按 `request_id` 与业务日志关联。

## 性能类

### 流式输出一顿一顿？

- 代理缓冲
- 弱网
- 客户端 UI 渲染节流

### 延迟突然升高？

- 上游渠道抖动
- 被限流排队
- 冷启动或区域路由变化
